# Changelog

## 2026-11-27 — Research workspace source snapshot

- Unified multi-image and GeoTIFF analysis in one local workspace.
- Added persisted projects, queued processing, pause/resume, retry, and exact duplicate handling.
- Improved conservative placement of compatible photographs and separation when correspondence is insufficient.
- Interactive crown/point/coverage layers, area statistics, PNG export and printable area reports.
- Added offline project and frontend contract tests and clearer public documentation.
- Replaced fixed demo sign-in credentials with isolated, randomly generated local demo identities; operational accounts cannot use demonstration role buttons.

This release is a research prototype and a source snapshot. It is not a hosted service or a release of the trained model, manuscript or raw research data.
